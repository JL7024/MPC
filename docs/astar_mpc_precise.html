这张图按当前代码实现重画：区分场景构建、MPC 初始化一次、每拍闭环循环、MPC 单次求解内部。

相对原图的主要修正

  • find_nearest() 不在 MPC 内部，而是在 run_simulation() 每一拍调用，然后把 nearest_idx 传给控制器。
  • MPC 的 _build_problem() 只在初始化时执行一次；每拍只更新 cvxpy Parameter.value 并调用 prob.solve(OSQP)。
  • 参考窗口不是简单取“最近点后 N 个索引点”，而是 get_reference_window_by_time() 按 v_ref * dt 沿弧长插值得到。
  • 参考控制不是独立预先生成的完整控制序列，而是在 solve() 内由曲率临时反推：delta_ref = atan(L*kappa)，a_ref = 0。
  • EKF 不直接参与 A* 规划，也不改变参考轨迹；它只改变控制器看到的反馈状态 state_for_ctrl。
  • A* 场景只是在场景构建阶段生成 ref.points；闭环里 MPC 只是跟踪这条参考轨迹。
